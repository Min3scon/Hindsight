Docs

Everything about Hindsight 1.0.0-beta.2 on one page. It's a beta: object recording passed most of its release test gate on Blender 5.0.1, 5.1.1 and 5.1.2 on Windows, but the long soak runs and the fixes from the latest review aren't finished, and it hasn't been tried on macOS or Linux. Back up your files.

Install

Hindsight needs Blender 4.2 or newer. The steps, and how to remove it, are on the install page. Object recording is off until you switch it on: see Turn on object recording.

Quick start

  1. Select a mesh and enter Sculpt Mode. A slider appears along the bottom of the viewport.
  2. Sculpt. Each stroke is one step, and the counter at the right end of the slider goes up.
  3. Drag the slider to go back, or press Ctrl Z and Ctrl Shift Z to move one step at a time.
  4. Save the file. The history is saved with it and comes back when you open it.

The slider

The slider sits along the bottom of every 3D Viewport while the active object has a history, and in Sculpt Mode as soon as you enter it. It keeps clear of the brush shelf, the toolbar and the sidebar.

  • Drag anywhere along it to scrub. A click jumps to that step.
  • The ring at its left end opens the History Menu.
  • The numbers on the right are the current step and the number of steps.
  • A short blue mark shows the morph target, if one is set.

Height, width, margin and colours are in the On-screen slider panel of the tab and in the add-on preferences.

The Undo History tab

Press N in the 3D Viewport and open Undo History. It works in every mode and without the on-screen slider, so it's the place to look if anything seems missing.

  • The slider and arrows go back and forth through the active object's history. The line below says which step you're on.
  • Record: switches appear when the Record preference is Everything: Everything on this object, and Objects added and deleted.
  • History Menu holds global history, the morph target, and the options to clear or pause recording.
  • History options, Movie Mode, Collection Filtering, Memory and On-screen slider are collapsed until you need them.
  • Help has Run self-check, Copy diagnostics and Report a bug.

The same controls are in the header button next to the mode menus, and F3 finds Step Back, Step Forward, Open History Menu, Run Self-check and Copy Diagnostics if you type "hindsight".

What gets recorded

Sculpting is recorded by default. That covers Sculpt Mode strokes and filters (vertex positions, masks, face sets, hidden faces) and topology changes such as Voxel Remesh, which store a full copy of the mesh for that step.

Objects are opt-in. Until you switch it on, only sculpting is recorded. Once it's on for an object, its transforms, parenting, constraints, collections, visibility and Edit Mode steps are recorded too. See Turn on object recording.

A stroke is recorded when you let go of the mouse, so one stroke is one step. A step stores only what the stroke changed, which is why jumping back and forth is exact. An object's history starts at its first stroke. For what isn't recorded, see Limitations.

Edit Mode step by step

With object recording on for an object, each Edit Mode operation is its own step, so you can go back through them one at a time. This works on meshes up to 300,000 vertices. Above that, a visit to Edit Mode is one step.

On an object that already has a sculpt history but no object recording, a visit to Edit Mode is one step.

Going back and sculpting again

If you go back and then sculpt, the steps after the current one are dropped, the same way Ctrl+Z works. If that would drop 10 steps or more, Hindsight asks first and your stroke is undone until you confirm. The number is a preference.

Morph History brush

Go to a step you liked, open the History Menu and choose Set morph target. Go back to the latest step, choose Use Morph History brush, and paint. Wherever you paint, the mesh moves toward its shape at the target step.

Light strokes give a partial blend. The rest of the mesh stays as it is, and the result is a normal step you can scrub past.

The brush respects the sculpt mask. It doesn't work with shape keys, Multires or Dyntopo.

Movie Mode

Movie Mode plays the history on the timeline. Turn on global history, tick Movie Mode in the tab, then use Quick auto key to set frames per step.

Playing or scrubbing the timeline then steps through the history, and you can render it like any animation. The history itself can't be changed while Movie Mode is on.

Global history

By default each object has its own history. Global history (History Menu > Global history) puts every object's steps on one timeline, in the order you made them. One operation is one position on it.

With Follow object and mode on, stepping to another object's change selects the object the step belongs to and puts it in the mode the change was made in.

Collection Filtering

Choose collections to leave out (blacklist) or to record exclusively (whitelist). Objects that are filtered out record nothing and their existing history is hidden, not deleted.

Join, separate, duplicate

These apply to sculpt histories.

  • Join (Ctrl J) merges the histories. Scrubbing back past the join brings the original objects back, each with its own history.
  • Separate (P in Edit Mode) and Mask Extract give the new object its own empty history, after asking.
  • Duplicate (Shift D) starts the copy with its own empty history.
  • Linked duplicates (Alt D) share mesh data, so they share history too. A warning says so when you make one.

Saving and recovery

By default the history goes in a folder next to the .blend, named after it: scene.blend gets scene_hindsight. Keep the two together when you move or share the file. In the preferences you can store it inside the .blend instead, or both.

The file format has a version number and a checksum per step. If part of a history file is damaged, the steps before the damage still load and the tab tells you what was lost.

A file saved by a newer Hindsight is left alone, not overwritten. Older files from beta 1 load as they are.

If Blender closes unexpectedly, the next open loads the history as it was last saved. Set On open to Unsaved steps in the preferences to also bring back steps made after the last save.

Memory

All histories together are kept under a limit, 4096 MB by default. When it's reached, the oldest steps go first and the tab says so. Each object keeps at most 10,000 steps.

Recent steps stay uncompressed for instant scrubbing. Older ones are packed: Hindsight stores how much each changed value moved, predicts that from the values next to it, and compresses what is left with Zstandard. Nothing is rounded, so every step comes back exactly as it was.

The Memory panel in the tab shows what each object uses.

Troubleshooting

I don't see anything after installing

Press N in the 3D Viewport and look for the Undo History tab. If it isn't there, open Edit > Preferences > Add-ons, search for Hindsight and check it's ticked. The slider itself only shows in Sculpt Mode, or once an object has a history.

Strokes aren't recorded

The tab says why: recording paused for this object, Multires or Dyntopo switched on, or the object filtered out by Collection Filtering. If none of those apply, open Help in the tab and click Run self-check.

The tab says part of Hindsight was switched off

Something raised an error. That one part (for example the on-screen slider) was switched off so nothing else breaks, and your history is untouched. Run self-check to switch it back on, and please send the diagnostics.

History folder missing

The file was saved with its history in a _hindsight folder that isn't next to it any more. Put the folder back beside the .blend and open the file again.

Blender's undo after a jump was reversed

After Hindsight moves the mesh while you sculpt or paint, Blender's own undo can't go back past that point without mixing up stroke data. Hindsight undoes Blender's undo in that case and says so. Use Ctrl Z or the slider instead. Leaving and re-entering the mode resets this.

Reporting a bug

Click Copy diagnostics in the Help panel and paste the text into a bug report. It has versions, settings, the self-check result and the last log lines, with your paths removed.

FAQ

How do I turn on object recording?
In the add-on preferences set Record to Everything, then select an object and click Everything on this object in the Undo History tab. The steps are on the install page.
Why wasn't my object move recorded?
Object recording is off until Record is Everything and the object's Everything on this object switch is on. The sidebar says so on an object that isn't recorded.
Does it work with Multires or Dyntopo?
Sculpt recording pauses on an object with Multires or Dyntopo, and the tab says why. It resumes on a normal mesh, once Multires is removed or Dyntopo is off.
Why was my sculpt not recorded?
Multires or Dyntopo is on, recording is paused for the object, or Collection Filtering leaves it out. The tab says which. Otherwise open Help in the tab and click Run self-check.
What doesn't it record?
Modifiers, node trees, materials, UVs, animation, shape keys, armatures and other object types aren't recorded. The full list is on the limitations page.
Does it replace Blender's undo?
Only while you sculpt or paint: there, Ctrl+Z and Ctrl+Shift+Z step through the object's history. Everywhere else Blender's undo works as normal.
Can I share a file with its history?
Yes. Send the _hindsight folder with it, or switch the preferences to store the history inside the .blend.
Is it free?
Yes, under the GPL 3.0 or later. The source is on GitHub.

Known issues

  • Tested on Windows only, on Blender 5.0.1, 5.1.1 and 5.1.2. It hasn't been tried on macOS or Linux.
  • Multires and Dyntopo pause sculpt recording on that object. The tab says why, and recording resumes on a normal mesh.
  • Modifiers, Geometry Nodes inputs, node trees, materials, weight paint, UVs, texture paint, animation, shape keys, armatures and other object types aren't recorded.
  • Object recording is off until Record is Everything and the object's Everything on this object switch is on.
  • Edit Mode step by step works up to 300,000 vertices. Above that, one step per Edit Mode visit.
  • Linked duplicates share one mesh, so its changes are recorded once, in one object's history.
  • After Hindsight moves the mesh while you sculpt or paint, Blender's own undo can't go back past that point. Hindsight reverses it and asks you to use Ctrl+Z or the slider.
  • Movie Mode: if playback crosses a remesh while the object is in Sculpt Mode, that frame shows the old topology for a moment. Render from Object Mode.
  • If you sculpt from an earlier step and that drops the step set as the morph target, the target is cleared. Set it again.
