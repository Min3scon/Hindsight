Limitations

Version {{version}} is a beta. Object recording passed most of its release test gate on Blender 5.0.1, 5.1.1 and 5.1.2 on Windows. The long soak runs and the fixes from the latest review aren't finished, and it hasn't been tried on macOS or Linux. Back up your files.

What it records

  • Sculpting, by default: Sculpt Mode strokes and filters, and topology changes such as Voxel Remesh.
  • Vertex Paint isn't part of what this beta claims: its strokes go into the history too, but one release check still fails on Blender 5.0.1.
  • Objects, once you switch them on: transforms, parenting, constraints, collections, visibility, adding and deleting objects, and Edit Mode step by step. Turn on object recording.

Known limits

  • Multires and Dyntopo pause sculpt recording on that object, and the tab says why.
  • Animated or driven properties aren't recorded, because they follow the animation.
  • Physics and particle systems of an object that the global history deleted and brought back don't come back. A note on such objects says so.
  • Edit Mode step by step works up to 300,000 vertices. Above that, it is one step per visit.
  • Linked duplicates (Alt+D) share one mesh, so its changes are recorded once, in one object's history.
  • Objects linked from another .blend file aren't recorded, because they can't be changed in this file.
  • A name that another object already has can't be given back. Blender adds .001 and the tab says so.
  • Each object keeps up to 10,000 steps. The oldest go first.
  • Going back over a topology change such as a remesh keeps vertex groups and shape keys, but their weights and shapes aren't recorded with that step unless Record > Everything is on for that object.
  • An object's own history can't bring back a parent or constraint target that is deleted now, and a note says so. The global history can.
  • Collections you make or delete are undone only when Objects added and deleted is on.
  • Changes made in a session without Hindsight become one step when the file is opened. If the mesh itself was changed without Hindsight, that object's history is left out and a message says so.

Multires adds subdivision levels to sculpt on. Dyntopo, short for dynamic topology, adds and removes faces while you sculpt. History resumes on a normal mesh, once Multires is removed or Dyntopo is off.

Not recorded in this version

These aren't recorded in this version:

  • Modifiers aren't recorded.
  • Geometry Nodes inputs and node trees aren't recorded.
  • Materials aren't recorded.
  • Weight paint isn't recorded.
  • UVs aren't recorded.
  • Texture paint isn't recorded.
  • Animation isn't recorded.
  • Shape keys aren't recorded.
  • Armatures aren't recorded.
  • Other object types, such as curves, text, lights and cameras, aren't recorded.
  • Scene settings aren't recorded.
