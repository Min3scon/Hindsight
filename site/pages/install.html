Install

  1. Download hindsight.zip ({{size}}). Keep it zipped.
  2. In Blender, open Edit > Preferences > Get Extensions. Click the small arrow at the top right and choose Install from Disk. Pick the zip. Hindsight is switched on straight away.
  3. In the 3D Viewport, press N and open the Undo History tab.

Hindsight needs Blender 4.2 or newer. To remove it, open the Get Extensions page, find the Hindsight entry and choose Uninstall.

Sculpting is recorded straight away

Enter Sculpt Mode and sculpt. Each stroke is one step. Drag the slider at the bottom of the 3D Viewport to go back, or press Ctrl Z and Ctrl Shift Z to move one step at a time.

Save the file and the history is saved with it.

Turn on object recording

Object recording is off until you switch it on. Until then, only sculpting is recorded. It works on Blender 5.x.

  1. Open Edit > Preferences > Add-ons, find Hindsight and open its preferences. Set Record to Everything. The other choice, and the default, is Sculpting only.
  2. Select an object. In the 3D Viewport press N, open the Undo History tab, and under Record: click Everything on this object. From then on, that object's changes are recorded.
  3. To also record objects being added, deleted or duplicated, click Objects added and deleted under Record:. This one is for the whole scene.

On an object that isn't recorded, the sidebar says: "To record this object, switch on Record > Everything on this object." Once it is switched on, the sidebar says: "Hindsight is on. Changes to this object are recorded from here on."

For an object that is switched on, Hindsight records:

  • Transforms: location, rotation with its rotation mode, scale and delta transforms.
  • Parenting: parent, parent type and bone, and parent inverse.
  • Constraints: adding, removing, reordering, renaming and their settings.
  • The collections the object is in, and its visibility: viewport, render, selectable and hidden with H.
  • Adding, deleting, duplicating and renaming objects, when Objects added and deleted is on.
  • Edit Mode step by step: each Edit Mode operation is its own step, on meshes up to 300,000 vertices. Above that, one step per Edit Mode visit.

The full list of limits is on the limitations page.

Global history

Each object has its own scrubbable history. Open History Menu > Global history to put every object's steps on one timeline, in the order you made them. One operation is one position. Follow object and mode selects the object a step belongs to.
