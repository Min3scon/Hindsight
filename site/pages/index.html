What it does

A timeline for every object

Scrub one object's history with the slider, or use the global timeline to see all of them in order.

Objects and Edit Mode

Transforms, parenting, constraints, collections, visibility, and adding, deleting, duplicating and renaming objects. Each Edit Mode operation is its own step. This is opt-in.

Morph History brush

Set a step as the morph target, then paint it back onto part of the mesh.

Movie Mode

Plays the history on the timeline so you can render a timelapse.

Install

  1. Download hindsight.zip. Keep it zipped.
  2. In Blender, open Edit > Preferences > Get Extensions, click the small arrow at the top right, choose Install from Disk and pick the zip. Hindsight is switched on straight away.
  3. In the 3D Viewport press N and open the Undo History tab.

To turn on object recording, follow the install guide.

Beta Status

Object recording passed most of its release tests on Blender 5.0.1, 5.1.1 and 5.1.2 on Windows. The long soak runs and the latest fixes aren't finished. Not tried on macOS or Linux.
