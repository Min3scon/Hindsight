# Optimisation log

One row per optimisation round, numbered in the order the work happened. Written 2026-11-18 from
`PERF_LOG.md`, the agent reports in `dev/reports/` and the commit messages. Where a number is missing
the cell says "not measured" or "no report".

## What a round is

A round is one hypothesis about one thing that was slow or large, with a measured before and after under
stated conditions. It ends kept or reverted. Both count.

- A round needs evidence for the problem (a profile or a counted cost), a change, and a before and an
  after measured the same way.
- Re-running a benchmark is not a round. A cosmetic edit is not a round. Changes made only for
  correctness are not rounds (they are in `DEFECTS.md`).
- A change with no measured effect beyond run-to-run noise is reverted, and logged reverted if a number
  exists. Items tried or considered without any number go in the list under the table. They are not
  rounds and are not counted.
- If two reports describe the same change it is one row. If one report measured several changes only
  together, they are one row and the cell says so.
- Conditions say sizes, Blender version and how it was measured: "alternating A/B" means the old and
  the new build were run in alternating processes (A B A B, at least 3 rounds, usually 5), "in-process"
  means both paths in one process, "single run" means one run. All machine times come from a shared
  4-core Linux VM (Intel Xeon 2.1 GHz, no GPU, load average often 5 to 14), so differences under about
  15 to 40 percent are noise unless the row says otherwise. "5.3.0 module" means Blender 5.3.0 as a
  Python module (headless), Python 3.13. No row was measured in a real Blender window.
- Numbers are in the units the source used. "old / new" pairs are before / after.
- The format 3 compression work at the top of `PERF_LOG.md` (stored size per step) happened before this
  job and is not backfilled: it measured size, not these rounds.
- Rounds from the agent MOVIE are listed but not counted: that work is on an unmerged branch.
